# Git Nudge

A lightweight, zero-dependency VS Code and Antigravity extension that monitors workspace changes and prompts you to commit and push updates to GitHub with one click.

## Features
- Automatically prompts to commit and push after 2 minutes of coding inactivity.
- Displays a persistent `Commit (X)` status bar button whenever uncommitted changes exist.
- Generates commit messages automatically with options to **Yes**, **Edit Message**, or **No**.
